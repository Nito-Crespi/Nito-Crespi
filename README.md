### 👨‍💻 About me

I'm **Álvaro Crespi Liut** (aka **Nito**), a software developer based in **Santa Fe, Argentina**, building software professionally since **2019**.

I started my career on the **backend** — Java, Spring, Node — and over time grew into a **full-stack** developer. These days my day-to-day leans heavily into the **frontend**, where I genuinely enjoy the craft: turning fuzzy requirements into clean, fast, accessible interfaces.

I care about agile ways of working, good communication, and writing code that the next person (often, future-me) can actually maintain.
